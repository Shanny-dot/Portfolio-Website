# Shantanu Fadnavis — Portfolio Website

> ML Engineer → AI Quality & Test Automation

A single-page interactive 3D portfolio — built as a **QA Mission Control** dashboard. Dark navy background, glowing emerald accents, Three.js node-graph animation, interactive flip cards, live test suite simulator, and real-world bug hunt case files.

## Stack

- **React** (Vite)
- **Three.js / React Three Fiber** — 3D wireframe node-graph hero
- **Tailwind CSS v4**
- **Framer Motion** + **Lucide React**

## Sections

1. **Hero** — Name, title, interactive 3D test-coverage graph, live terminal
2. **What I Test** — 3 interactive flip cards (DataObserve ML pipeline, API validation, LLM eval)
3. **The Bug Hunt** — Real incident case files from internship work
4. **Toolkit** — Filterable skill grid with detail inspector
5. **Projects** — SneakerHeadLM, SmallAnimeLM, Beautiful Story Generator as evaluation case studies
6. **Metrics Dashboard** — Live test suite runner with SVG charts and streaming log feed
7. **Contact** — Terminal-style form + direct links

## Running locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
